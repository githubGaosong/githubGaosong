# GameTranslator 极简 Windows 版

仅包含：
- 粘贴游戏文字，在线翻译为简体中文
- F5：翻译并显示弹窗
- F4：显示/隐藏置顶弹窗
- 鼠标左键拖动弹窗
- Windows x64 单文件、自包含发布

## 使用
1. 启动 GameTranslator.exe。
2. 将游戏中的文字粘贴到主窗口。
3. 按 F5 翻译并显示结果。
4. 按 F4 显示或隐藏翻译弹窗。

## 限制
- 当前版本不含 OCR，不能自动读取游戏画面。
- 普通置顶窗口不能保证覆盖真正的独占全屏 DirectX/Vulkan 游戏；建议使用无边框窗口全屏或第二显示器。
- 翻译使用 MyMemory 公共 API，需要联网，可能受服务限流。提交的文本会发送给该第三方服务。
- F4/F5 是全局快捷键，若被其他软件占用会提示注册失败。
